VisualSim

A collection of self-contained generative visual simulators, built for making stills and loops rather than for shipping into a product. Every simulator is a single HTML file with no build step, and every parameter is on a panel you can open, drag and export.

Hover a card to run it in place. Open one for the full-screen version and its controls. Several simulators read their own canvas back to export, so file:// will not do; serve the folder over a local server.

Gradient Spin

A CSS loading spinner blown up into a full-screen wavefront field.

DataPulse

Braided fiber bundles flowing between two nodes, as a tube or as a brushed-silk sheet.

datapulse/

Pixel Bars

A pixel-art bar spectrum with a noise-blended palette and harmony accents.

pixelBars/

Shader Gradient

A four-stop gradient cut by hard-edge parabolic horizon arcs.

Particle Globe

A dotted globe with a procedural land mask and great-circle connection arcs.

Fluid Folds

Domain-warped fractal noise, shaded as folded liquid metal.

fluidfolds/

Wave Lights

Three interfering wave trains lit as a thin iridescent horizon.

Logomark Background Builder

A tiling logomark pattern over a configurable gradient, exported as PNG or WebP.
